# 準備 Kobrixa 與 EV3

## 完成目標

建立並開啟 Kobrixa 專案，確認 EV3 可以安全連線。第一次進行馬達課程前，請將輪子架高。

## 開始前

- 安裝 Kobrixa 開發版，或依[安裝說明](/docs/reference/installation)從原始碼啟動。
- 準備一台 EV3 與 USB 線；Wi-Fi 只在同一個可信任網路中使用。
- 先只連接一台 EV3，發生問題時可停止程式、重新連線後再試。

## 建立流程

1. 選擇「建立專案」，使用 `bp` 與 `ev3-native` 預設值。
2. 開啟 `src/main.bp`，儲存後按「建置」。成功建置會產生 `.rbf` 成品。
3. 搜尋 USB EV3，或輸入 Wi-Fi 位址；連線後才可上傳與執行。

## 安全規則

不要在馬達被桌面、手指或線材卡住時執行程式。感測器課程前，確認感測器接在指定輸入埠。USB 與 Wi-Fi 上傳在 v1 candidate 仍持續進行跨平台實機驗證。
