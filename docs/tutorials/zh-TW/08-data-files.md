# 集合與檔案

## 完成目標

理解固定長度資料、數字 Vector 與 EV3 專案檔案的用途。

```bp
Number[] readings
Vector.New(readings, 3)
Vector.Set(readings, 0, 42)
value = Vector.Get(readings, 0)
```

使用 `Number[]` 或 `String[]` 宣告陣列。`Row.*` 適合固定列資料，`Vector.*` 可建立與操作數字集合。檔案課程會寫入 EV3；請使用專案名稱與明確流程，避免覆蓋未知資料。
