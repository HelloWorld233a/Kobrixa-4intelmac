# Language / 語言

<a href="../README.md">English index</a> · <a href="../README.zh-TW.md">繁中索引</a>

Demonstrate Basic Plus source-language behavior that applies across every EV3 API category.

示範適用於所有 EV3 API 類別的 Basic Plus 來源語言行為。

Kobrixa accepts both bare `true` / `false` and legacy quoted `"True"` / `"False"` in Boolean contexts.

Kobrixa 在布林情境中同時接受裸 `true`／`false` 與舊式帶引號的 `"True"`／`"False"`。
